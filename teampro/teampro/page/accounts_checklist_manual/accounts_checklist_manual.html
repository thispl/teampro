1. Overview

The Accounts Checklist tool helps the accounts team track daily, weekly, monthly, quarterly, and yearly accounting tasks — both internal (bookkeeping, reconciliation, MIS) and statutory (GSTR, TDS, EPF, ESI, PT, ITR, audit).

Each period, the system auto-generates a checklist from a master template. Users update item statuses as they complete tasks. Progress is monitored via two reports:

  • DPR (Daily Progress Report) — per-task detail across a date range
  • DSR (Daily Status Report) — daily rollup with completion % and category breakdown
Quick start: Open the Accounts Checklist list → click the checklist for the current period → update each item's Status → attach proof (challan/return PDF) → check DPR or DSR for monitoring.

3. Accounts Checklist Template

The template is the master list of all checklist items. A default template ACT-00001 ("Default Accounts Checklist") is pre-loaded with 34 items.

How to edit the template

  1. Go to Accounts Checklist Template list
  2. Click ACT-00001 to open it
  3. Add / edit / remove rows in the Items table
  4. For each item set:
    • Item Title — the task name
    • Category — Internal Accounts / Statutory / Management MIS / Audit Year-end
    • Frequency — Daily / Weekly / Monthly / Quarterly / Yearly
    • Is Statutory — tick if this is a legal compliance item
    • Compliance Reference — e.g. GSTR-1, TDS, EPF
    • Priority — High / Medium / Low
    • Statutory Due Day — day of month the item is due (e.g. 11 for GSTR-1). 0 = use period end.
    • Applicable Months — "All" or comma-separated (e.g. "Jun,Oct" for Form 16 / ITR)
    • Assigned To Role / User — who is responsible
  5. Click Save
Note: Changes to the template affect future generated checklists only. Already-generated checklists keep their original items.

Generate a checklist from the template

Click the Generate Checklist for Period button on the template. This creates an Accounts Checklist for the selected frequency and current date.

5. Accounts Checklist (Generated Instances)

Each generated checklist is a transaction document covering one period. Examples:

NameFrequencyPeriod
ACC-Daily-04-Aug-2026-#####Daily04-Aug-2026
ACC-Weekly-Week 03-Aug-2026-#####WeeklyWeek 03-Aug-2026
ACC-Monthly-Aug 2026-#####MonthlyAug 2026
ACC-Quarterly-Q3 2026-#####QuarterlyQ3 2026
ACC-Yearly-FY2026-2027-#####YearlyFY2026-2027 (Apr–Mar)

Header fields (auto-computed)

  • Total Items — count of all items
  • Completed — items marked Completed
  • Pending — items in Pending or In Progress
  • Overdue — items past due date and not completed
  • Not Applicable — items marked N/A
  • Completion % — completed / (total − N/A) × 100
  • Status — Open / In Progress / Completed / Overdue (auto)

Working with items

  1. Open the checklist for the current period
  2. Scroll to the Checklist Items table
  3. For each item, update:
    • Status — Pending / In Progress / Completed / Not Applicable / Overdue
    • Attachment / Proof — upload the challan, return PDF, or screenshot
    • Remarks — any notes (e.g. "Filed via portal, ARN: 12345")
  4. Completed By and Completed On are auto-stamped when status = Completed
  5. Click Save
Tip: Use the Mark All In Progress button to bulk-update all pending items to "In Progress" at the start of the day.

6. Generation — Auto & Manual

Auto Generation (Scheduler)

When Enable Auto Generation is ticked in Settings, the scheduler creates checklists automatically:

FrequencySchedule
DailyEvery day at 06:00
WeeklyEvery week (Monday)
Monthly1st of each month
Quarterly1st of Jan / Apr / Jul / Oct at 06:30
Yearly1st April at 07:00 (Indian FY start)
Overdue sweepDaily at 23:00 — marks past-due items as Overdue

If a checklist already exists for a period, it is not duplicated.

Manual Generation

  • From Settings: Click "Generate Today's Checklists" → creates all frequencies for today
  • From Template: Click "Generate Checklist for Period" → creates one frequency for today
  • Via bench: bench --site <site> execute teampro.teampro.doctype.accounts_checklist.accounts_checklist.generate_manual --kwargs '{"frequency":"Monthly","ref_date":"2026-08-01"}'

7. Item Statuses & Workflow

StatusMeaningAuto-set?
PendingNot yet started (default on generation)Yes (on generation)
In ProgressWork started but not finishedManual or via "Mark All In Progress"
CompletedTask done; completed_by and completed_on auto-stampedManual (auto-stamps user/time)

Important: Overdue status is set by the nightly scheduler. If the scheduler is paused, items will not auto-mark overdue. You can also manually set a status to Overdue.

8. DPR — Daily Progress Report

Path: Search "Daily Progress Report" or go to /app/query-report/Daily Progress Report

The DPR shows per-item detail across a date range. Use this to see exactly which tasks are done, pending, or overdue, and by whom.

Filters

9. DSR — Daily Status Report

Path: Search "Daily Status Report" or go to /app/query-report/Daily Status Report

The DSR shows a daily rollup — one row per checklist with summary counts, completion %, and per-category breakdown. Includes a bar chart of Completed / Pending / Overdue by period.

Filters

FilterDescription
From DateStart of the date range
To DateEnd of the date range
FrequencyFilter to a specific frequency

Columns

Date, Frequency, Period, Checklists, Total Items, Completed, Pending, Overdue, N/A, Completion %, then per-category (Internal Accounts, Statutory, Management MIS, Audit Year-end) counts and done counts.

Tip: The DSR is ideal for management review — it shows at a glance how many statutory items are pending and the overall completion percentage for each period.

12. FAQ & Troubleshooting

Q: Checklists are not auto-generating. Why?

A: Check that Enable Auto Generation is ticked in Accounts Checklist Settings, and that the Frappe scheduler is running (bench schedule or supervisor). Also verify a Default Template is set.

Q: How do I backfill a checklist for a past period?

A: Use manual generation via bench: bench --site <site> execute teampro.teampro.doctype.accounts_checklist.accounts_checklist.generate_manual --kwargs '{"frequency":"Monthly","ref_date":"2026-07-01"}'

Q: An item shows Overdue but I already completed it. Why?

A: The overdue sweep runs at 23:00 nightly. If you completed the item after the sweep ran, simply set the status back to Completed and save.

Q: How do I add a new statutory compliance item?

A: Open the template (ACT-00001) → add a new row in the Items table → set Category = Statutory, Is Statutory = ticked, Compliance Reference, Frequency, and Statutory Due Day → Save. The next generated checklist will include it.

Q: Can I have different templates for different companies?

A: Yes. Create multiple Accounts Checklist Template records, each with a different Company. Then set the appropriate one as Default Template in Settings, or pass the template name when generating manually.

Q: The DPR/DSR report shows no data. Why?

A: Make sure checklists have been generated for the date range you're filtering on. Generate them first (manually or via the Settings button), then re-run the report.
